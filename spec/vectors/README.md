# Conformance vectors

Generated by `npm run vectors` (tools/vectors/) from the JavaScript originals at the pinned commits; never edited by
hand. `npm run vectors -- --check` regenerates them and compares byte for byte. The tiers and their tolerances are in
`spec/conformance/tiers.md`; `manifest.json` lists every file with its size and SHA-256 (8.77 MB in all).

**Sources** (`tools/pins.json`):
- my-3d2dge `14a561c031fd2b9649606d4f3ac7baae1c2dbbfe` (https://github.com/michaelcrosato/my-3d2dge)
- my-3d2dge-2 `c8295dc0300ffa1ccadcf4702668ff412b735c39` (https://github.com/michaelcrosato/my-3d2dge-2)
- shardfall `a9ca003069db3da9245de1e1e21d5d288140f41e` (https://github.com/michaelcrosato/shardfall)
- my-3dge `652ea6bc0affdce2943f5705ee2c5fa167ddbbaa` (https://github.com/michaelcrosato/my-3dge)
- riftlight `f3693fca0039bdeda5918083bfa28b4a7b8a82af` (https://github.com/michaelcrosato/riftlight)

**Numbers** are the shortest decimal that parses back to the same double, `-0` kept. Body points are in the origin's
POINTS order (36 points, each forward, right, up), millimetres in tiers 1a and 3, whole micrometres in tier 2.

| Path | Tier | What it holds |
|---|---|---|
| `tier1a/rig.json` | 1a | The tiny rig's captured body points, the measured rest, and per clip reduce, fit and text (bit for bit) |
| `tier1a/cmu-09_02.json` | 1a | The same for two picks of CMU take 09_02 (a loop cut at its best cycle, and a burst) |
| `tier1b/rig.gltf` | 1b | The tiny rig as glTF JSON (buffer embedded); packed as .glb it is the reader's input (its SHA-256 is in tier1a/rig.json) |
| `tier1b/rig-catalog.json` | 1b | The catalog the importer read for the rig (tags, descriptions) |
| `tier1b/rigify.gltf` | 1b | A Rigify rig with a skinned mesh (strided, normalized and short accessors), STEP and scale tracks and a turned, scaled root |
| `tier1b/rigify-expected.json` | 1b | Its captured body points, rest and mannequin look as the origin's importer read them (bit for bit) |
| `tier1b/cmu/` | 1b | CMU subject 09's skeleton (`09.asf`), take 09_02 (`09_02.amc`) and the picks catalog |
| `tier2/<SET>.json` | 2 | Every curated clip decoded on its reference body at each key and at three in-betweens; mirror and text checks |
| `tier2/FORMAT2.json` | 2 | Format 2's hand, fingers, spine and yaw on six clips, decoded by `@m3a/core` (their reference, D2) |
| `tier3/bodies.json` | 3 | Bodies of other proportions: seven generated rigs and the sets' own bodies |
| `frozen/` | frozen | Fixtures from my-3dge, checked by SHA-256 and never regenerated (below) |

**Frozen fixtures:**
- `frozen/core.json`: my-3dge tests/baselines/port/core.json (generated there from my-3d2dge@e37e4eedcd23326f3734188b9574a4aa635fcbd3, not our pin): math helpers, RNG and easing; SHA-256 `4a0f7439c61ae259922e10654a2f3a738d488667d3fa9b67ed2d75d6b4d11f3b`
- `frozen/moves.json`: my-3dge tests/baselines/port/moves.json (generated there from my-3d2dge@e37e4eedcd23326f3734188b9574a4aa635fcbd3, not our pin): the move model; SHA-256 `cb623bd598aa72ad5d6f37dc409dc47bab50cbcf5fb8ab88c95e3c38a89fe5d5`

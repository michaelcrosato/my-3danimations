# B6 starter

- `character.glb`: the character the grader plays the punch on (a skinned humanoid, glTF, metres, facing +Z).
- `punch.json`: the recipe to write (the m3a recipe format: `node_modules/@m3a/tools/MANUAL.md`, "Make").
- `check.ts`: `npm run check` compiles it against the CC0 library and prints what the grader reads.

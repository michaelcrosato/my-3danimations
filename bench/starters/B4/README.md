# B4 starter

- `character.glb`: the avatar (a skinned humanoid, glTF, metres, facing +Z, VRM humanoid bone names).
- `src/character.ts`: loads it with three.js (given).
- `src/sneak.ts`: the sneak to write (`createSneaker`).
- `check.ts`: `npm run check` drives your sneaker as the grader will and prints what its bones do.
- `node_modules/@m3a/*`: the animation packages; start with `node_modules/@m3a/tools/MANUAL.md`.
